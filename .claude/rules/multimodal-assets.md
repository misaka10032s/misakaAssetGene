# Multimodal asset rules

1. Every feature design must support both modes: a single asset and a **composite asset pack**, which must consider at least these composable elements: images, character lines, character voices, songs/BGM, video, animated stills.
2. Version control must be able to track the members of a whole output pack, their dependencies, and the source prompts.
3. The consultant flow must be able to break the task down first, then decide the generation order of each modality and the delivery formats.
