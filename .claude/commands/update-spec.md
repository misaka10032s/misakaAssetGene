# /project:update-spec

After a requirement is confirmed, update the spec and planning documents in step.

## Must do
1. Update the relevant sections and the changelog of `docs/superpowers/specs/spec.md`
2. If the workflow or roles are affected, update `CLAUDE.md` / `.claude/` in step
3. Record a summary of this change in `.plan/RESEARCH_LOG.md`
4. Mark completed items **「已完成」**

## Forbidden
- Making a large change to the spec without a requirement discussion
- Changing only the documents without syncing the changelog or the research log
